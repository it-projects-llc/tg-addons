 Website modifications for Tribal Gathering
============================================

* When user register on website, allowed company ids is taken from portal template user

Terms and conditions for website
--------------------------------

* Main menu -> Website -> Configuration -> Websites

* Open any website

* Set TNC URL and TNC Title

* In browser's private mode navigate to signup url

* RESULT: you will see TNC checkbox with given TNC URL, which is required to pass registration

* Register user

* As admin open contact of registered user

* RESULT: in contact form -> Sales and Purchase -> Misc -> "Accepted TNC" is true
