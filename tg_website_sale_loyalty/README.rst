Nationality discount program
----------------------------

Configuration method 1
----------------------

* Go to Sales -> Products -> Discount & Loyalty

* Create or open existing program with type "Discount code"

* Add minimal condition with discount code if not exists

* Add rewards if not exist

* In "Nationality programs" section add nationality

* Save

Configuration method 2
----------------------

* Go to Sales -> Products -> Nationality discounts

* Create row with nationality and corresponding discount code program

* RESULT: in new row you will see populated discount code from given discount code program

Usage
-----

* Login as user, which nationality is included in discount program

* Register in event

* RESULT: discount program is automatically applied, if minimal condition is met
