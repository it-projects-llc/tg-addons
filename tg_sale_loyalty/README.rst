=================================================
 Sale Loyalty modifications for Tribal Gathering
=================================================

* Trims coupon code, when attempt to use in sale order

* If product is reward of loyalty program, loyalty program can be accessed from smart button of products' form

Loyalty Program
---------------

* Introduces "Is accumulative" field, which falsy values disallow to apply program with other programs applied in order
