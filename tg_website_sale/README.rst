===============================================
 eCommerce customizations for Tribal Gathering
===============================================

* In shop/address page

  * Hides following fields:

    * "VAT"

    * "Company name"

    * "Street and Number"

    * "Apartment, suite, etc"

    * "Zip Code"

    * "City"

    * "State"

  * Hides "email" field for registered user
