===========================================
 Rental modifications for Tribal Gathering
===========================================

Payment status
--------------

This module adds "Payment status" field in rental orders.

For non-rental orders it is calculated as "Not rental order".

This value can be used for filtering in menu "Rental -> Orders".
Field is shown in search panel on left side.

On developer mode, it's value can be seen in sale/rental order form -> "Other info" tab
